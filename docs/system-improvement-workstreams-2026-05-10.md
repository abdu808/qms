# خطة تنظيف وتحسين النظام

هذه الوثيقة تحول ملاحظات المستشارين إلى مسارات عمل قابلة للتنفيذ داخل النظام، دون هدم الخطة المعتمدة أو إرهاق الفريق.

## 1. الخطة والاستراتيجية

الهدف: تحويل الخطة من بيانات متفرقة إلى خريطة قرار.

تم تنفيذه:
- إضافة معايير قبول لخريطة ترابط الخطة.
- إضافة قرار جاهزية: جاهزة، جاهزة مشروطة، غير جاهزة.
- إضافة الإجراء التالي بناء على أول فجوة مؤثرة.
- ربط اللوحة التنفيذية بصحة الخطة.

المتبقي:
- ربط SWOT تلقائيا بالمخاطر والأهداف.
- عرض خريطة استراتيجية مرئية مختصرة للإدارة.

## 2. الأهداف والمؤشرات

الهدف: منع المؤشر الغامض أو غير المملوك.

تم تنفيذه:
- فحص مالك الأداء، مالك البيانات، جهة الاعتماد، تردد القياس، المستهدف السنوي، التعريف، المصدر، ووحدة القياس.
- تمييز المانع الحقيقي عن التنبيه التحسيني.

المتبقي:
- وزن المؤشرات داخل كل محور عند اعتماد أوزان رسمية.
- ربط الانحراف التلقائي بخطة إجراء مبسطة.

## 3. الأنشطة والمبادرات

الهدف: جعل النشاط لغة التنفيذ اليومية للفريق.

تم تنفيذه:
- فحص وجود إدارة منفذة ومسؤول لكل نشاط.
- فحص وجود مالك وإدارة وتواريخ لكل مبادرة.

المتبقي:
- شاشة مبسطة تعرض للموظف: نشاطي، مؤشري، الدليل المطلوب، آخر موعد.
- تحويل الأنشطة المتأخرة إلى مهام متابعة عند الحاجة.

## 4. لوحة القرار التنفيذي

الهدف: صفحة واحدة تقول للإدارة: أين الخطر؟ وما القرار المطلوب؟

تم تنفيذه:
- إضافة صحة ترابط الخطة ومعايير القبول إلى اللوحة التنفيذية.
- إضافة تنبيهات قرار تشمل جاهزية الخطة، مهام المتابعة، وملاحظات التدقيق الحرجة.

المتبقي:
- تبويب "قرارات هذا الشهر" يجمع: المتأخرات، الانحرافات، CAPA، مراجعة الإدارة.

## 5. النظافة التقنية

الهدف: أخطاء أوضح وصيانة أسهل.

تم تنفيذه:
- إظهار requestId في أخطاء API حتى يمكن تتبع البلاغات من الواجهة إلى السجلات.
- الإبقاء على Global Error Handler موحد.
- تثبيت أن Zod موجود فعليا في أغلب الوحدات الحساسة.

المتبقي:
- توسيع Zod على المسارات اليدوية القديمة.
- مراجعة N+1 في بعض الخدمات الدورية الكبيرة.
- إضافة فهارس انتقائية بعد مراقبة الاستعلامات البطيئة في الإنتاج.

## معيار الانتقال للمرحلة التالية

لا ننتقل لتوسيع الذكاء الاصطناعي أو التكاملات الخارجية قبل تحقق الآتي:
- لا توجد مشكلات حاكمة في خريطة ترابط الخطة.
- كل مؤشر له مالك أداء، مالك بيانات، جهة اعتماد، وتردد قياس.
- كل نشاط رئيسي له إدارة ومسؤول.
- اللوحة التنفيذية تعرض قرارا واضحا لا مجرد رسوم.
## تحديث الدفعة الثالثة

تم استكمال التحسينات التشغيلية الآتية:
- ربط SWOT عملياً بخريطة صحة الخطة عبر معيار قبول جديد.
- إضافة فحص صحة SWOT لمعرفة العناصر غير المرتبطة بخطر أو هدف أو مالك متابعة.
- إضافة مسار لتحويل عنصر SWOT إلى خطر/فرصة، ومسار آخر لتحويله إلى مهمة متابعة.
- تحويل انحرافات KPI الأقل من 80% إلى مهام متابعة دون تكرار لنفس القراءة.
- عرض مهام المتابعة الشخصية ضمن "مهامي" حتى يرى الموظف ما عليه فعله مباشرة.

التقييم بعد هذه الدفعة:
- الترابط الاستراتيجي: تحسن من عرض فجوات فقط إلى آلية معالجة.
- إدارة المؤشرات: تحسنت لأن الانحراف لم يعد رقماً ساكناً بل مهمة متابعة.
- تجربة الموظف: تحسنت لأن "مهامي" أصبحت تجمع المؤشرات، الإقرارات، المسودات، ومهام المتابعة.
- المتبقي الحقيقي: تحسين الواجهة المرئية للخريطة الاستراتيجية وإضافة تبويب قرارات شهرية أكثر اختصاراً.
